# studio —— 第二代主页的三套方向

这里是第二代个人主页的生成器。三套方向共用一份数据（根目录 `build.py` 里的 `WORKS` / `POC` / `PRINCIPLES`）、
一套排版工具，各自出一整页 README。个人主页现在用的是「零」：

| | 长卷（`scroll.py`） | 零 · 灰与橙（`zero.py`） | 极光 Pro（`aurora_pro.py`） |
| --- | --- | --- | --- |
| 一句话 | 山是 AI 写下的代码，卷上的朱印是我盖的 | 灰色的代码是 AI 的产出，橙色是我的判断 | 作品集同一套品牌，工艺拉满 |
| 首屏 | 一卷从右往左展开的手卷：行楷「一行代码 / 没写」、朱丝栏里竖写的引言、一笔账（我写的〇行，AI 写的八万零八十四行），底下是十五个仓库连成的远山 | 铺满 codeless 仓库里 AI 写的真代码，按整字挖出一个「0」—— 只挖笔画那一圈，0 里照样是代码，正中一个从不打字的光标 | 一整片夜空：分隔线过了文字就升起来，变成极光的底边 |
| 截图 | 调成墨色印在纸上，像挂在山上的一幅画；底下那座山就是画出这一屏的源文件 | 一律去色（那是 AI 的产出）；每件作品唯一的橙色是「它替谁解决什么」那一句 | 原色，放进玻璃卡片里，底下一团项目色的光 |
| 字体 | 马善政楷书 + 思源宋体 + Instrument Serif + Geist Mono | Instrument Serif + 思源宋体 + Geist + 思源黑体 | Geist + 思源黑体 |
| 预览 | [`styles/scroll/`](../styles/scroll/) | [`styles/zero/`](../styles/zero/) | [`styles/aurora-pro/`](../styles/aurora-pro/) |

```sh
python3 studio/build.py                   # 三套都生成到 styles/ 下
python3 studio/build.py --home zero       # 「零」生成到仓库根目录 —— 个人主页上显示的就是它
python3 studio/build.py --home scroll     # 换成「长卷」
```

依赖：`pip install fonttools brotli pillow`。不需要联网，也不需要原始字体和作品集仓库 ——
用到的字切好的母版在 `studio/fonts/`，截图处理好的小图在 `studio/shots/`，分词结果在 `studio/seg.json`，
「长卷」用到的行长和代码摘录在 `studio/skyline.json`、`studio/code/`，行数就从行长表里数。
改了文案、出现了母版里没有的字，build 会报错，提示带上原始字体重切：`FONTSRC=<目录> python3 studio/build.py --masters`。

## 每张图都遵守的几条

**两条竖线。** 桌面画布宽 1692 = GitHub 个人主页 README 栏 846px 的两倍（1 单位 = 0.5px），
手机画布 648 = 390 宽手机上 324px 的两倍，同一套换算：字号 28 就是 14px。
「零」只有两条竖线：页面边 0（编号挂在这里）和正文线 96；「极光 Pro」卡片内边一律 64、标题贴页面边。

**段落节奏是算出来的。** GitHub 在每张图后面加 22px 段距，图片是行内元素，行尾还有 6px 空隙。
所以每一段的图都在底部留 60 单位，段与段之间一律 116 单位（58px）；标题到内容一律同一个距离。

**字宽是量出来的，不是估的。** 字体切成子集嵌进每张 SVG（一张只嵌它用到的那几十个字，10～70 KB），
用 fontTools 读字宽表排版：右对齐、折行、「接在一段字后面的小标签」都是像素级准的。
中文按词折行（jieba 分词，结果缓存），避头尾，「AI Native」「Docker + CI」这类词组不拆，句号、破折号处优先折，
末行不留孤字、也不留一个孤零零的西文词；三行以上、栏宽够 22 个字的正文齐行（`textLength` 两端对齐，
「的」「了」不打头），手机上的窄栏和短句右边参差。

**手机单独排版。** 每张图出四份：桌面 / 手机 × 亮 / 暗，用 `<picture>` 按宽度和主题切换。
手机版一直用到 1151px —— 窗口窄于 1152 时 GitHub 的 README 栏不到 720px，桌面版缩过去正文不到 12px。
手机版正文最小 12px（画布上 24），只有加了字距的西文大写小标签用到 10～11px。

**动效克制，而且不费电。** SVG 当图片显示时，只要有动画在跑，整张图每一帧都要重画，
所以大面积的东西一律不用 mask / filter 做动画：代码墙的淡出用渐变填充，极光的光幕是径向渐变的矩形，
颗粒是一块 160px 的噪点小图平铺。出场动画只播一遍，播完的样子就是默认样子 ——
不播动画的地方（「减少动态效果」、截图、预览）看到的就是完成态。Chrome 里滚到之前图片的时间轴是停着的，
所以出场动画会在看到它的那一刻才播。

**不摆示意图。** 截图全部来自作品集仓库 `decli.github.io/shots/`，按区块裁、放大到界面上的字看得清；
裁切线都落在界面本身的空隙上（逐行逐列找底色一致的带），不切字、不切卡片，手机另裁一块更小的。
插件弹窗这种小窗口原尺寸摆在底色上，跟浏览器里一样从工具栏徽标底下掉下来；弹窗里的 IP、城市、时区那几行不露。
首屏那面代码墙是 codeless 仓库 `poc/agent/` 里真实的源码；$0.0127、13 次调用出自 `docs/06-poc-findings.md`。

**地点。** 旧主页写的「San Jose」跟作品集对不上（作品集里没有这个地名，倒是 IP 插件截图里的代理出口是 San Jose），
新版先不写；要写就改 `content.py` 里的 `CITY`。

## 长卷是怎么画的

**一卷，不是一摞图。** 手卷从右往左看，README 从上往下读，所以把卷子裁成一段一段摞起来：
引首（右头带着卷轴、包首的锦和题签）→ 一整幅「八万行代码」的江山 → 六段作品 → 十五张签条 → 题跋（左头是另一根轴）。
每一段自己从右往左读：题字在右，画在左。段与段之间各出一条 18 单位的锦边，摞起来正好是装裱里的「隔水」。

**拼缝是零。** GitHub 把图片当行内元素排，图和图之间会露出几像素的行距缝 ——
「零」用段距把它吃掉了，长卷要的是一整张纸。所以整卷放在同一个 `<p>` 里、每张 `<img align="top">`：
顶对齐的行内图不再给字的下伸部留位置，一张接一张严丝合缝。（`align="left"` / `"right"` 会被 GitHub 加 20px 内边距，不能用。）

**近山就是代码。** 每件作品那张截图底下的山，是画出这一屏的源文件（`Dashboard.tsx`、`CleanView.swift`……）：
去掉缩进，一行接一行，竖排着从右往左一列一列灌进山形里，从山脊往下读。山形是这个文件自己的行长。
等宽字 20 单位 = 10px，凑近了每一行都读得出来。摘录跟作品集首页透视层是同一份
（作品集仓库 `code/<slug>.json`，两个仓库并排 clone 时自动刷新 `studio/code/`）。

**远山是整个仓库。** 远山的轮廓是那个仓库**全部**代码每一行的长度，八万零八十四行一行不少
（`studio/skyline.json`，在作品集仓库里跑 `node tools/harvest.mjs --repos <放十五个仓库的目录> --skyline ../decli/studio/skyline.json` 生成）。
代码的行长本身起伏不大，直接画是一块平台 —— 所以先粗抹平定山势（哪一段写得满，哪里就是主峰）、
再细抹平定山石，按这一座山自己的最高和最低拉开。山多高跟代码量走（开平方），信风最高，TabInfoCopy 只是一块石头。
江山图上每座山头挂一张地名签，像旧舆图那样竖写山名，挤不下就往两边让，拉一根细线指回山顶。

**印是人的判断。** 古画上，画是画师的，印是鉴藏的人的 —— 盖印就是「我看过、我认」。
一件作品一方印，在它那一段、签条上、题跋的印谱里各出现一次。印文是作品名里的汉字，全西文的就刻西文；
用思源宋体最粗那一档，不冒充篆书；按面积定大小，两个字的长条印不会比方印显得大一号。每件作品那句话旁边的朱笔圈点（`EMPH`）是审稿的人圈出来的那几个字。

**竖排按竖排的规矩来。** 标点用 Unicode 的竖排形式（`︐︒︑︓` ……，思源宋体都有，位置是字体设计师摆好的），
两个以内的西文字母、数字横着挤进一格（纵中横），更长的西文词、空格连着的西文词组（AI Native）整体转九十度；破折号画成一根线。
一句话要折成几列，就把字平均分到几列里，不会剩一两个字孤零零占一列。数目字带位数的写「零」（八万零八十四），〇只留给那个朱红的「我写的代码〇行」。
引言写在朱丝栏里（信笺上一道道朱红的竖格），一句一起头；每件作品那句话、题跋在哪里换列都是手定的
（`BRIEF_COLS`、`COLO`），文案改了、换列表没跟上时自动退回按高度折。

**纸是接着的。** 签条一张一张是分开的图，纸上的纤维和茶渍噪点按整卷的坐标取样（`paper(..., oy=)`），拼起来纹理是连着的，看不出接缝。
暗色模式下纸压暗、偏旧，像放久了的绢；小字和朱红的字在两种纸上都过 4.5:1。

**落款跟着时间走。** 题跋末尾「丙午秋 decli 识」是按生成那天算的干支和季节；要钉住就设 `SOURCE_DATE_EPOCH`。

**加一件作品。** 签条、江山图、印谱都跟着 `WORKS` 自动长出来；印文没在 `SEAL_TEXT` 里写的，取名字里的前两个汉字。
想让它上一整段，改 `scroll.py` 的 `FEATURED`，再在 `content.py` 的 `SHOT` 里给它定一块截图、
在作品集仓库的 `code/<slug>.json` 里有那张截图的源码摘录。
